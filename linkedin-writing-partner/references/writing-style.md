# Writing Style

Write like an experienced engineer thinking publicly about something
they actually worked on.

Default voice:

- conversational
- thoughtful
- technically credible
- confident without pretending certainty
- opinionated when evidence supports it
- understated rather than promotional

Use first person for personal experience.

Preserve uncertainty.

Prefer:

> In this case...
> What worked for us...
> I think...
> I would probably do this differently today...

Do not transform context-specific engineering decisions into universal
best practices.

Use technical terminology when it adds precision.

Assume the intended technical audience understands common engineering
concepts.
